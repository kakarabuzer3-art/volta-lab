DC-DC Converter Fundamentals

A DC-DC converter changes one steady voltage into another. Volta Lab needs one because its battery pack sits at a fixed voltage while the output can be set anywhere from 0 to 415 V.

Simulation only. This page explains a software model. It is educational material, not engineering or safety advice.

Switching, not dissipating

A resistor can lower a voltage, but it turns the difference into heat. A switching converter instead chops the input on and off many thousands of times per second and uses an inductor and a capacitor to smooth the result. The fraction of each switching period during which the transistor is on is the duty cycle, D.

The two ideal relations

◆ Physical law For an ideal converter in continuous conduction mode (the inductor current never falls to zero), balancing the inductor's volt-seconds over one period gives:

  • Buck (step-down): Vout = D · Vin, so D = Vout / Vin.
  • Boost (step-up): Vout = Vin / (1 − D), so D = 1 − Vin / Vout.

Illustrative ideal (loss-free) arithmetic using the default pack's nominal voltage of about 372.6 V: a 220 V DC output needs a buck duty of about 220 / 372.6 ≈ 0.59, and a 415 V DC output needs a boost duty of about 1 − 372.6 / 415 ≈ 0.10. Real converters need slightly more because of losses.

Losses and efficiency

≈ Engineering approximation Volta Lab uses an averaged model: it follows the cycle-averaged behaviour and does not simulate individual switching edges. Input power is the output power plus three loss terms:

Pin = Pout · (1 + ksw) + Pfixed + Rcond · Iin2

The terms are a switching loss proportional to output power, a fixed control and gate-drive loss, and a conduction loss that grows with the square of the input current. Efficiency is then a result, η = Pout / Pin, never a number typed in. Because the battery has internal resistance, the input current is found by solving a quadratic; if the discriminant is negative the source simply cannot deliver that power.

Duty limits

◇ Illustrative assumption The machine's converter is limited to a duty cycle of at most 0.9 (a model assumption). With a non-isolated boost, the maximum ideal gain is therefore 1 / (1 − 0.9) = 10, and a request beyond what the limit allows is reported as a duty-limit condition rather than silently shown as achieved.

Ripple

≈ Engineering approximation Inductor ripple uses the standard continuous-conduction formula ΔIL = Vin · D / (L · fsw) for a boost stage. Only the formulas are used; no waveform is drawn.

What Volta Lab does with it

  • In DC mode the machine compares the requested voltage with the battery's open-circuit voltage and treats the stage as a buck if the request is lower, a boost if it is higher.
  • The Controls panel shows the converter's input current, efficiency and loss, so you can watch loss rise with load.
  • The converter has a thermal model and shuts down above a shutdown temperature, restarting only after it cools below a lower restart temperature (hysteresis). Both temperatures are assumed values.

What it does not do

It does not model discontinuous conduction, individual transistor switching, electromagnetic interference, or any specific commercial converter. All loss coefficients, the switching frequency (50 kHz), the inductor and capacitor values are illustrative assumptions, not datasheet values.
